# Drift Vehicles

![Drift Vehicles](./logo.svg)

**Vehicles, fuel, cargo, seats, durability, traversal costs, routes, and vehicle actions.**

Drift Vehicles is a first-party Helios module isolated behind the shared module contract so games can enable, replace, or extend this subsystem independently.

## Contract

- Module id: `drift-vehicles`
- Category: `vehicles`
- State namespace: `world.modules.drift-vehicles`
- Integration: event-driven and capability-safe

## Status

Experimental 0.x reference module.
