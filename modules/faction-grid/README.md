# Faction Grid

![Faction Grid](./logo.svg)

**Factions, membership, reputation, diplomacy, hostility, alliances, territory claims, and social state.**

Faction Grid is a first-party Helios module isolated behind the shared module contract so games can enable, replace, or extend this subsystem independently.

## Contract

- Module id: `faction-grid`
- Category: `factions`
- State namespace: `world.modules.faction-grid`
- Integration: event-driven and capability-safe

## Status

Experimental 0.x reference module.
