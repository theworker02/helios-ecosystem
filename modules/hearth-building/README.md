# Hearth Building

![Hearth Building](./logo.svg)

**Construction, structures, rooms, placement, upgrades, utilities, ownership, and settlement state.**

Hearth Building is a first-party Helios module isolated behind the shared module contract so games can enable, replace, or extend this subsystem independently.

## Contract

- Module id: `hearth-building`
- Category: `building`
- State namespace: `world.modules.hearth-building`
- Integration: event-driven and capability-safe

## Status

Experimental 0.x reference module.
