# Chronicle State

![Chronicle State](./logo.svg)

**Save games, checkpoints, snapshots, rollback-safe histories, migrations, and portable world persistence.**

Chronicle State is a first-party Helios module isolated behind the shared module contract so games can enable, replace, or extend this subsystem independently.

## Contract

- Module id: `chronicle-state`
- Category: `state`
- State namespace: `world.modules.chronicle-state`
- Integration: event-driven and capability-safe

## Status

Experimental 0.x reference module.
