# Atlas Worlds

![Atlas Worlds](./logo.svg)

**World, region, scene, biome, location, travel, and procedural world-generation primitives.**

Atlas Worlds is a first-party Helios module isolated behind the shared module contract so games can enable, replace, or extend this subsystem independently.

## Contract

- Module id: `atlas-worlds`
- Category: `worlds`
- State namespace: `world.modules.atlas-worlds`
- Integration: event-driven and capability-safe

## Status

Experimental 0.x reference module.
