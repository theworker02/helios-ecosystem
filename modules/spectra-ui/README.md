# Spectra UI

![Spectra UI](./logo.svg)

**Declarative HUDs, panels, menus, meters, interaction prompts, and renderer-neutral presentation schemas.**

Spectra UI is a first-party Helios module isolated behind the shared module contract so games can enable, replace, or extend this subsystem independently.

## Contract

- Module id: `spectra-ui`
- Category: `ui`
- State namespace: `world.modules.spectra-ui`
- Integration: event-driven and capability-safe

## Status

Experimental 0.x reference module.
