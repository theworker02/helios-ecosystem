# Loom Quests

![Loom Quests](./logo.svg)

**Objectives, quest graphs, prerequisites, branching outcomes, rewards, and progression tracking.**

Loom Quests is a first-party Helios module isolated behind the shared module contract so games can enable, replace, or extend this subsystem independently.

## Contract

- Module id: `loom-quests`
- Category: `quests`
- State namespace: `world.modules.loom-quests`
- Integration: event-driven and capability-safe

## Status

Experimental 0.x reference module.
