# Keystone Physics

![Keystone Physics](./logo.svg)

**Lightweight spatial rules, collision intents, movement costs, occupancy, ranges, and deterministic resolution.**

Keystone Physics is a first-party Helios module isolated behind the shared module contract so games can enable, replace, or extend this subsystem independently.

## Contract

- Module id: `keystone-physics`
- Category: `physics`
- State namespace: `world.modules.keystone-physics`
- Integration: event-driven and capability-safe

## Status

Experimental 0.x reference module.
