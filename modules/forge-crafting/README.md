# Forge Crafting

![Forge Crafting](./logo.svg)

**Recipes, ingredients, tools, stations, crafting queues, quality, and production events.**

Forge Crafting is a first-party Helios module isolated behind the shared module contract so games can enable, replace, or extend this subsystem independently.

## Contract

- Module id: `forge-crafting`
- Category: `crafting`
- State namespace: `world.modules.forge-crafting`
- Integration: event-driven and capability-safe

## Status

Experimental 0.x reference module.
