# Resonance Audio

![Resonance Audio](./logo.svg)

**Music states, ambient layers, sound cues, spatial audio intents, and adaptive soundtrack events.**

Resonance Audio is a first-party Helios module isolated behind the shared module contract so games can enable, replace, or extend this subsystem independently.

## Contract

- Module id: `resonance-audio`
- Category: `audio`
- State namespace: `world.modules.resonance-audio`
- Integration: event-driven and capability-safe

## Status

Experimental 0.x reference module.
