# Relay Multiplayer

![Relay Multiplayer](./logo.svg)

**Player sessions, authority rules, state deltas, turn synchronization, presence, and co-op primitives.**

Relay Multiplayer is a first-party Helios module isolated behind the shared module contract so games can enable, replace, or extend this subsystem independently.

## Contract

- Module id: `relay-multiplayer`
- Category: `multiplayer`
- State namespace: `world.modules.relay-multiplayer`
- Integration: event-driven and capability-safe

## Status

Experimental 0.x reference module.
