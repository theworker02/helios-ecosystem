# Bazaar Economy

![Bazaar Economy](./logo.svg)

**Currencies, shops, pricing, scarcity, trade, inventories, and configurable market simulation.**

Bazaar Economy is a first-party Helios module isolated behind the shared module contract so games can enable, replace, or extend this subsystem independently.

## Contract

- Module id: `bazaar-economy`
- Category: `economy`
- State namespace: `world.modules.bazaar-economy`
- Integration: event-driven and capability-safe

## Status

Experimental 0.x reference module.
