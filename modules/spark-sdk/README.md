# Spark SDK

![Spark SDK](./logo.svg)

**Developer-facing module SDK, manifests, hooks, schemas, compatibility checks, examples, and module test harnesses.**

Spark SDK is a first-party Helios module isolated behind the shared module contract so games can enable, replace, or extend this subsystem independently.

## Contract

- Module id: `spark-sdk`
- Category: `sdk`
- State namespace: `world.modules.spark-sdk`
- Integration: event-driven and capability-safe

## Status

Experimental 0.x reference module.
