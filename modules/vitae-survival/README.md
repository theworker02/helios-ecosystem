# Vitae Survival

![Vitae Survival](./logo.svg)

**Health, hunger, thirst, fatigue, temperature, disease, injury, recovery, and survival pressure.**

Vitae Survival is a first-party Helios module isolated behind the shared module contract so games can enable, replace, or extend this subsystem independently.

## Contract

- Module id: `vitae-survival`
- Category: `survival`
- State namespace: `world.modules.vitae-survival`
- Integration: event-driven and capability-safe

## Status

Experimental 0.x reference module.
