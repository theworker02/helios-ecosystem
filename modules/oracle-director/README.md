# Oracle Director

![Oracle Director](./logo.svg)

**AI game-master and narrative-director hooks for pacing, encounters, tension, goals, and adaptive story beats.**

Oracle Director is a first-party Helios module isolated behind the shared module contract so games can enable, replace, or extend this subsystem independently.

## Contract

- Module id: `oracle-director`
- Category: `director`
- State namespace: `world.modules.oracle-director`
- Integration: event-driven and capability-safe

## Status

Experimental 0.x reference module.
