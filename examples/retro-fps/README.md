# Helios Retro FPS Example

This example demonstrates the v1.3.8 retro-FPS runtime. It uses a tiny original map made from `#` walls, `.` floor and `P` as the player spawn.

The runtime performs collision-aware movement and DDA ray casting, then can return either structured ray distances or a text-native ASCII frame suitable for ChatGPT.

It is **Doom-style**, not a copy of Doom. Helios also includes a reader for user-supplied classic IWAD/PWAD metadata and geometry, but no Doom executable, WAD, textures, sounds, maps or other proprietary data are included.
